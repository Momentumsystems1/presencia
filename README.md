# Presencia — Instaflash Group

Repositorio maestro para la presencia digital pública de Instaflash Group y sus entidades relacionadas.

## Objetivo

Construir una presencia corporativa verificable, coherente e indexable por buscadores y sistemas de IA, preservando la separación entre hechos documentados, información confirmada por dirección, información pendiente de evidencia y contenido no publicable.

## Fuente inicial

La fuente de recuperación es la exportación completa del proyecto de Atoms entregada por dirección el 25-09-2026. La exportación contiene 257 entradas e incluye el frontend React/TypeScript, estrategia SEO/entity/Knowledge Graph, documentación corporativa, activos visuales y documentación fuente.

## Estructura objetivo

- `website/` — web pública y código fuente.
- `strategy/` — SEO, entity strategy, Knowledge Graph, autoridad externa y roadmaps.
- `corporate-intelligence/` — contexto corporativo gobernado.
- `evidence/` — índice de evidencias y certificaciones; no publicar material sensible automáticamente.
- `seo/` — Schema.org, JSON-LD, sitemap, robots, canonical, hreflang y metadata.
- `audit/` — auditorías, contradicciones, pendientes y decisiones.
- `archive/atoms/` — preservación del material original de Atoms.
- `deployment/` — configuración de despliegue e indexación.

## Gobierno de información

`CODE ≠ PRODUCT VISION ≠ CORPORATE FACT ≠ STRATEGIC HYPOTHESIS`

Ningún contenido interno queda autorizado para publicación por el mero hecho de existir en este repositorio. Relaciones societarias, porcentajes de propiedad, cargos jurídicos y claims regulatorios requieren el nivel de evidencia correspondiente.
